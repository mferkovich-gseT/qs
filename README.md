# Como levantar a aplicação

No diretório raiz do repositório, execute:

```
./mvnw quarkus:dev
```

# Jogando pelo navegador

Depois de subir o servidor, abra:

```
http://127.0.0.1:8080/jankenpo?escolha=PEDRA
```

O parâmetro aceita três palavras, sempre em maiúsculas:

- PAPEL
- PEDRA
- TESOURA
